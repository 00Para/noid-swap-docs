Welcome to No1d Swap

No1d Swap is a desktop app for Windows and macOS that lets two people swap NOID (Parano1d) for ETH (Ethereum) directly—with no bridge, no wrapped token, no liquidity pool, and no middleman.

A hash-time-locked contract on each chain holds the coins. Neither contract has an owner, an admin key, a pause button, or a protocol fee. Either both people receive what they agreed on, or both get their own coins back automatically once the deadlines pass.

Warning:

Read before swapping real funds: No1d Swap is early software built for two people who have a reason to trust each other, and for small amounts only. Start with Is No1d Swap Right for You Today? and Limits & Risks.

Note:

Parano1d has no test network. Even when you choose Ethereum Sepolia, the NOID side is always real Parano1d mainnet NOID. If you want to test the app with zero coins and zero setup, use the built-in Practice Swap first.

What No1d Swap Is—and Isn't

  • It is a self-custodial atomic swap app between two known counterparties.
  • It is not an exchange, order book, broker, or custodial wallet.
  • It does not set prices. You and the other person agree on the amounts elsewhere (for example, in chat or on a call), then enter those exact amounts into the app.
  • It has not had an outside audit yet. Every security review so far was done internally by the project. Keep amounts small.

Where to Start

  1. Decide if it fits your swap: Read Is No1d Swap Right for You Today? (2 minutes).
  2. Understand the mechanics: Skim How It Works so the order of steps and deadlines makes sense.
  3. Install safely: Follow Download & Verify the Installer to verify the signed release notice and file hash before opening the installer.
  4. Rehearse with fake coins: Run the 5-minute Practice Swap from the app menu.
  5. Run your first swap: Follow the Swap Overview & Two-Person Checklist together with your counterparty.
